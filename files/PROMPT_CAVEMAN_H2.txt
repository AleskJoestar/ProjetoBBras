## KNOWN BUGS — FIX IN ORDER

BUG1 [CRÍTICO] imports net.sf.jasperreports.* não resolvidos
  - JARs do JasperReports ausentes em lib/
  - baixar jasperreports-6.20.0 full zip e copiar todos os JARs para lib/
  - URL: https://sourceforge.net/projects/jasperreports/files/jasperreports/6.20.0/
  - atualizar .vscode/settings.json: "java.project.referencedLibraries": ["lib/**/*.jar"]

BUG2 [CRÍTICO] FuncionarioDao.java — senha com MD5 (incompatível com H2 e modo texto puro)
  - remover md5(?) de TODOS os SQLs de INSERT, UPDATE e SELECT do FuncionarioDao
  - INSERT: "...senha_fun) values (?,?,?,?,?,?,?,?,?)"  ← último ? direto, sem md5()
  - UPDATE: "...senha_fun=? where cod_fun=?"            ← sem md5()
  - SELECT login: "where cpf_fun=? and senha_fun=?"     ← sem MD5()

BUG3 [CRÍTICO] FuncionarioDao.java — nome da coluna endereço_fun (tem acento ç)
  - H2 tem problema com identificadores acentuados
  - substituir TODAS as ocorrências de "endereço_fun" por "endereco_fun" no DAO
  - mesma troca no mapeamento/Funcionario.java (getter/setter)

BUG4 [MÉDIO] DespesasDao.java — método atualizar() — SQL malformado
  - original: "update Despesas set valor_desp, desc_desp, data_Desp, hora_desp where cod_desp=?"
  - fix:      "update Despesas set valor_desp=?, desc_desp=?, data_Desp=?, hora_desp=? where cod_desp=?"

BUG5 [MÉDIO] RealizarVendasDao.java — método listaTodosprod()
  - resultado.getInt("cod_prod") → coluna não existe, nome real é "cod_prod_fk"
  - fix: resultado.getInt("cod_prod_fk")

BUG6 [BAIXO] VendasDao, RealizarVendasDao, CaixaDao — múltiplos ResultSets paralelos
  - loop para na menor quantidade de linhas entre os ResultSets
  - não impede execução, só pode truncar listagens
  - fix ideal: reescrever com JOIN; ignorar por ora se quiser só rodar
